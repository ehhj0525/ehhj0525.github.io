One-time setup

If a device that can already add photos is to hand, it can show a setup code for this one — no token to type. Otherwise, carry on below.

This device needs a GitHub token to add photos. Create a fine-grained personal access token with Contents: Read and write on the gallery repository, then paste it here. It is stored only in this browser.

Two things catch people out: create it while signed in as the account that owns this site, and under Repository access choose Only select repositories and tick that repository — a token that cannot see it fails with a bare “Not Found”.
